Avatar Me is an interactive avatar customization web app built with HTML, CSS, and JavaScript. It starts with a ready-made demo avatar, and users can personalize it by changing dresses, accessories, hijab styles, hair colors, and background themes. Once customized, the avatar can be downloaded as an image, making the app both fun and practical.

<!--more-->

## How it works

The app opens with an initial page that already presents a styled avatar model. From there, users can explore various customization options, including:

- changing outfits and dresses
- adding or removing accessories
- styling the hijab
- adjusting hair color and hairstyle
- switching background themes and visual settings

Each customization updates the avatar live, so users can instantly preview the look they want before downloading it as a final image.

## Features

- interactive avatar preview
- wardrobe and accessory customization
- hijab styling options
- hair color and hairstyle selection
- background/theme switching
- image download export
