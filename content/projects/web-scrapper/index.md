A multi-module web scraping application developed during the BrainStation-23 attachment. The project was designed to extract different types of data from the web, including tables, images, movie details, videos, product information, and PDF links, using Python, Flask, BeautifulSoup, and Selenium.

## Project Overview

This application was built as a practical data acquisition tool for real-world web content. It supports both static and dynamic scraping, allowing users to fetch structured data from websites using a simple interface and process it efficiently.

## Features

- **Table Scraping**: Extract and display tables from any webpage.
- **Image Scraping**: Fetch images with filtering by format (PNG, JPG) and limit the number of images displayed.
- **Movie Details Scraping**: Retrieve movie information (title, poster, year, rating, plot, genre) from IMDb using Selenium.
- **Video Scraping**: Fetch and display videos from a webpage with filtering by format (MP4, WEBM, OGG).
- **News Headline Scraping**: Extract readable headlines from online news sources.
- **eBay Product Scraping**: Retrieve product details such as title, link, image, price, and rating.
- **PDF Link Scraping**: Detect and collect PDF links from websites using static and dynamic scraping methods.

## Technologies Used

- **Python**: Core programming language.
- **Flask**: Web framework for the application.
- **BeautifulSoup**: Library for parsing HTML and XML.
- **Selenium**: Browser automation for dynamic content scraping.
- **MongoDB**: Data storage for extracted results.
- **Tailwind CSS**: Styling for the app interface.
- **pdfplumber**: Extracts data from PDF files.

## Why this project mattered

This project was created as part of a collaborative internship experience, where my team developed a modular platform to streamline web data extraction for multiple use cases. It reflects my interest in building practical automation tools that turn raw online content into structured, usable information.
